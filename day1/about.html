About QuickNotes

QuickNotes is a simple tool for creating and organising notes. It helps users keep important information in one easy-to-use place.

How to use QuickNotes

  1. Open QuickNotes.
  2. Create a new note.
  3. Write your information.
  4. Save your note.

Features

  • Create notes
  • Edit notes
  • Save notes
  • Organise information

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save a note
