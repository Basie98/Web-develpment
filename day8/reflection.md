# Day 8 Reflection

One of the biggest challenges I faced during this course was learning how to design a system that can handle a large number of users. I initially struggled to understand how APIs, databases, servers, and caching work together. I improved my understanding by following the system design framework step by step and applying what I learned to practical projects. Working on QuickNotes and TicketHub helped me understand the importance of planning system components, estimating traffic, and protecting data from errors such as double-booking seats.

After receiving feedback on my capstone project, I realised that I needed to improve the completeness and quality of my technical documentation. I would make the architecture clearer, provide more accurate traffic and storage estimates, document API endpoints and error responses, and explain database relationships in more detail. I would also test my application thoroughly and check that every required file is included before submitting the project.

My next learning goal is to develop my knowledge of cloud computing, particularly Microsoft Azure, and understand how applications are deployed and managed online. I also want to strengthen my JavaScript skills and learn to build a real backend API that connects to a frontend application and a database. I plan to achieve these goals by practising regularly, building small projects, testing my work, and using feedback to improve my skills.
