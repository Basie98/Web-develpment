# Day 8 Reflection

One of the biggest challenges I faced during this course was learning how to design a system that can handle many users at the same time. At first, I struggled to understand how APIs, databases, servers, and caching work together. I improved my understanding by following the system design framework step by step and applying what I learned to practical projects. Working on QuickNotes and TicketHub helped me understand traffic estimates, system architecture, and how database transactions prevent double-booking.

After receiving feedback on my capstone project, I realised that my technical documentation needed to be more complete and clearer. I would improve the architecture diagram, check my traffic and storage estimates, document the API endpoints and error responses, and explain how the database protects data. I would also test my application thoroughly and check that every required file is included before submitting my work.

My next learning goal is to develop my knowledge of cloud computing, particularly Microsoft Azure, and understand how applications are deployed and managed online. I also want to strengthen my JavaScript skills and learn how to build a real backend API connected to a frontend application and database. I plan to achieve these goals by practising regularly, building small projects, testing my work, and learning from feedback.
